```sh

PLAYWRIGHT_BASE_URL=http://127.0.0.1:4322 node qa/capture.mjs
```

截图覆盖 1440×900 两种视图及选中状态、390×844 两种视图及详情安全区、1024×800 地形。截图输出到当前目录，不纳入 Git；Mac 使用已安装 Chrome，其他系统使用 Playwright Chromium。

此次复核保留真实四领域（AI 技能化、商业化、职业化、社会化）、60 能力和 75 关系。星图额外的低亮度线表示真实的领域/二级领域归属，不作为能力关系。地形网格和建筑由本地确定性程序构建，表面使用 Poly Haven 的 CC0 Rocky Terrain 纹理；不使用参考截图作为背景。

视觉目标尚未完全达到：原图的写实岩石、细叶植被、自然环境光与不规则建筑仍比当前实时场景精细；场景构图也不等同于原图。现版本解决了四色圆盘、简单锥体树、细管桥梁、轨道状星团等主要实现问题，但不应标记为“像素级复刻完成”。

- 星图：调整领域位置与纵深，以柔光和透明度表达远近；非相关节点及关系在选中时仍保留；领域锚点使用柔和光晕，硬光圈只用于悬停与选择。
