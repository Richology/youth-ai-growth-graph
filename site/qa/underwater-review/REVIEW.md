## 画面问题与处理

| 观察到的问题 | 本地新版的处理 |
|---|---|
| 岩壁沿整个岸线垂直延伸，堵住下半部 | 顶部衔接岸线，下部逐渐内收；拓宽错位裂隙，增加深度不同的独立礁石 |
| 海床只剩底边窄条 | 宽阔沙地浅台、弯曲水道；相机同时考虑可用宽度和高度，默认/重置俯角一致 |
| 碎石有明显三角面或方砖轮廓 | 非规则体积、凹蚀裂缝与平滑连接的表面法线；否决了圆角方盒版本 |
| 水草太宽、分布集中 | 更细长的中脊叶片，九处疏密群落，按真实岩面/海床落脚，随水流弯曲 |
| 鱼群只在一个平面平移 | 两群银鱼与分散的金色鱼，共 48 条；独立转向、速度、间距和深度；身体后段传递摆动到尾部 |
| 鱼可能经过新礁石 | 路径与礁石共用位置/尺度，前视调整游动高度；模拟检查间距、加速度及水下边界 |
| 鱼数量增加带来绘制开销 | 三组鱼身/尾鳍实例化，共六个鱼类绘制对象 |
| 焦散像规则网格 | 空间扰动、变化的聚焦强度、较细的尺度和较柔和的亮度 |
| 近处石头也被染成蓝色 | 岩石与生物共用视线水程：取视线到水面或椭圆水域边缘的较短距离，近处保留材质色 |
| 岩壁缝隙露出页面背景 | 深度与场景覆盖率控制的柔和水域填充；不覆盖实体，避免海床上的颜色切面 |
