# Richology 青少年 AI 时代成长图谱

> 面向青少年 AI 创造与商业化教育的开放框架、能力图谱与实践方法论。

[English](README_EN.md) · [项目总纲](docs/project-charter.md) · [图谱规范](specification/graph-specification.md) · [参与贡献](CONTRIBUTING.md)

## 为什么做这个项目

我们希望回答的不只是“学生做出了什么作品”，还包括：

- 作品背后发展了哪些能力？
- 这些能力之间有什么依赖关系？
- 教师怎样据此设计课程与项目？
- 什么证据可以支持能力判断？
- 家长怎样理解一次学习经历带来的真实成长？

本项目将商业化理解为一个完整的价值创造过程：发现真实问题、与 AI 协作、形成作品、进入真实场景、获得反馈并持续迭代，而不只是教授赚钱技巧。

## 项目结构

本项目由三个彼此连接的部分构成：

| 部分 | 回答的问题 | 主要产物 |
|---|---|---|
| 开放框架 | 怎样理解青少年在 AI 时代的成长？ | 工作论文、概念模型、术语表 |
| 能力图谱 | 需要发展什么能力，能力如何关联？ | 节点、关系、等级、证据、跨领域路径与机器可读数据 |
| 实践方法论 | 教师和学生怎样使用图谱？ | 课程、项目、评价和家长沟通方法 |

一句话概括：**开放框架画出世界的边界，能力图谱标出其中的地点和道路，方法论告诉人们怎样在这张地图上行动。**

## 核心模型

### 三大人生课题

财富、健康、关系是本项目希望长期服务的人生方向，而不是三门课程，也不是可以由单节课直接实现的结果。

### 四个能力领域

1. **AI 技能化**：AI 边界、人机沟通与协作、判断与纠偏。
2. **商业化**：需求洞察、产品构建、市场验证。
3. **职业化**：项目管理、专业沟通、自我驱动。
4. **社会化**：社会感知、协作实践、规则意识。

### 四种实践深度

创造、创作、创新、创业不是另外四个并列的能力领域，而是学生综合运用能力、逐步进入真实世界的实践深度。

## 使用边界

- 不是经过验证的心理测量工具；
- 不是青少年的永久性能力标签；
- 不是已经获得学术共同体认可的行业标准；
- 不使用可识别未成年人的原始数据作为公开示例。

理论陈述区分为原则、实践观察、待验证假设与已有证据。节点状态和数据统计以 [`data/manifest.json`](data/manifest.json) 为准。

## 基本学习循环

```text
发现真实问题 → 与 AI 协作 → 做出作品 → 进入真实场景
              → 获得反馈 → 调整迭代 → 沉淀能力证据
```

## 仓库目录

```text
framework/       开放框架、工作论文与术语
specification/   图谱规范、关系、等级与证据标准
data/            机器可读的领域、能力和关系数据
schema/          JSON Schema
methodology/     课程、项目与评价方法
examples/        课程映射、项目证据与家长报告示例
rfcs/            重要改动的公开提案
tools/           校验、派生数据与发布清单工具
```

机器可读层已将节点、关系、外部框架映射、学习路径、受众说明和证据任务分离，并为完整文件提供 JSON Schema 与可复现哈希。这些数据可直接用于课程工具、2D/3D 关系图、搜索和面向不同受众的解释界面；应用仍须保留本项目的未成年人保护与非标准化测评边界。
