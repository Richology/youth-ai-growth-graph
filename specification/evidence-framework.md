# 能力证据框架 v0.1

## 1. 证据链

有效的能力判断至少说明：

```text
情境 → 学习者行动 → 产生的结果 → 反馈与调整 → 对应能力主张
```

只展示结果、不说明行动过程的材料，证据强度有限。

## 2. 五类证据

| 类型 | 内容 | 例子 |
|---|---|---|
| 过程证据 | 学习者如何思考和行动 | 版本记录、决策日志、提示词迭代 |
| 产出证据 | 行动形成的作品或结果 | 原型、调研报告、演示页面 |
| 解释证据 | 学习者能否说明理由 | 口头答辩、书面反思、方案取舍 |
| 反馈证据 | 他人或真实环境的回应 | 用户反馈、同伴评议、测试数据 |
| 迁移证据 | 能否用于新的任务或情境 | 在另一项目中独立应用同一能力 |

## 3. 证据强度

| 等级 | 描述 |
|---|---|
| S1 单点线索 | 单次、单一来源或高度依赖帮助，只能作为观察线索 |
| S2 情境证据 | 在明确情境中有过程与产出支持，可以作阶段性判断 |
| S3 交叉证据 | 多种证据来源相互印证，并包含反馈或学习者解释 |
| S4 迁移证据 | 在不同时间或新情境中重复表现，能根据反馈调整 |

证据强度与熟练度不是同一个维度。学习者可能表现出 E3 水平，但当前只有 S1 证据，因此仍不适合做稳定判断。

## 4. AI 参与声明

涉及 AI 的作品应尽量记录：

- 任务由谁定义；
- 关键提示和约束由谁提出；
- AI 生成了哪些部分；
- 学习者做了哪些选择、核验和修改；
- 最终结果由谁承担责任。

无法区分 AI 贡献和学习者贡献时，只能把作品作为弱证据。

## 5. 反证与限制

每个节点应列出容易产生误判的情况，例如：

- 完全照搬模板或 AI 输出；
- 只会复述术语，无法在任务中行动；
- 只在单一熟悉情境中成功；
- 结果好但过程包含不可接受的伦理或规则问题；
- 表现受到资源、语言、身体状态或环境机会的显著限制。

反证不是寻找学生缺点，而是限制评价者过度推断。

## 6. 家长报告表达

推荐表达：

> 在本次用户访谈项目中，学习者能够独立追问用户的具体经历，并根据两条反馈修改问题定义。该过程为“发现真实问题”提供了 S2 情境证据，当前表现接近 E3 独立应用。仍需观察其能否在其他主题中迁移使用。

避免表达：

> 孩子的商业洞察力达到 85 分，未来很适合创业。
