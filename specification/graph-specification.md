# 青少年 AI 时代成长图谱规范 v0.1

> 状态：Draft
> 本规范定义图谱的数据结构与使用边界，不代表其教育学有效性已经得到验证。

## 1. 规范目标

本规范让课程设计者、研究者、开发者和家长使用同一套语言，回答四个问题：

1. 我们所说的“能力”究竟是什么？
2. 不同能力之间怎样连接？
3. 什么表现可以说明能力正在形成？
4. 课程、作品和学习证据怎样映射回图谱？

## 2. 图谱的四层结构

| 层级 | 对象 | 作用 |
|---|---|---|
| L1 | 能力领域 Domain | 表示 AI 技能化、商业化、职业化、社会化四个一级方向 |
| L2 | 二级领域 Subdomain | 将一级领域拆成 12 个可管理的能力群 |
| L3 | 能力节点 Competency | 描述可发展、可观察、可迁移的人类能力 |
| L4 | 证据与情境 Evidence & Context | 记录能力在什么任务、作品和真实反馈中得到体现 |

领域是组织结构，不直接用于评价学生；能力节点才是课程映射和证据归因的基本单位。

## 3. 核心对象

### 3.1 能力节点

能力节点描述一个人能够在特定类型的情境中稳定采取的有效行动。它必须：

- 以人的行动为中心，而不是以某个工具为中心；
- 可以通过行为或产出被观察；
- 能在多个任务中重复出现；
- 可以通过练习、反馈和反思得到发展；
- 具有明确边界，避免与其他节点大量重叠。

### 3.2 关系

关系描述两个能力节点之间的结构联系。v0.1 只启用三种核心关系：

- `requires`：通常应先具备的必要基础；
- `supports`：有助于另一能力，但不是必要条件；
- `related_to`：存在重要联系，但当前不主张方向或依赖。

### 3.3 证据

证据是支持某项能力判断的可检查材料，包括过程记录、作品、行为观察、学习者解释和真实反馈。作品本身不是能力，只有结合情境和过程才能成为能力证据。

### 3.4 人生课题映射

能力可以与财富、健康、关系建立“可能贡献”映射，但该映射不构成直接因果声明。不得声称一节课或一个节点能够直接改善学生的人生结果。

## 4. 图谱与课程的关系

课程不是图谱节点。课程通过学习目标、活动、项目、证据和反思与多个能力节点建立映射：

```text
课程目标 → 目标能力 → 学习活动 → 项目产出 → 证据记录 → 能力判断
```

课程映射必须区分：

- **重点发展**：课程明确设计了练习、反馈和证据；
- **辅助涉及**：学生会用到，但课程没有专门教学或评价；
- **仅有曝光**：学生接触过概念，不能据此推断能力形成。

## 5. 版本与状态

所有能力节点均应包含版本和状态：

- `proposed`：已提出，尚未完成公开讨论；
- `draft`：定义和证据结构基本完整，仍可能明显调整；
- `stable`：经过多个版本、公开评议和跨情境检验；
- `deprecated`：不再使用，但保留 ID 和迁移说明。

节点 ID 一经公开不得复用。节点重命名不改变 ID；节点拆分或合并时，应创建新 ID 并记录替代关系。

## 6. 认识论边界

- “没有证据”只能表示尚未观察，不能自动解释为能力不足。
- 一次成功表现不足以证明稳定能力。
- 熟练度是基于具体情境和证据的阶段性判断，不是人的固定标签。
- AI 生成的精美作品不能单独证明学习者具备相应能力。
- 不在 v0.1 中计算综合能力分、排名、天赋类型或商业成功概率。
- 本图谱不是心理测量、职业测评或招生筛选工具。

## 7. 最小可用版本

v0.1 的最小可用图谱包含：

- 4 个一级领域；
- 12 个二级领域；
- 48–60 个候选能力节点；
- 三类核心关系；
- 四级熟练度描述；
- 能力证据与反证指引；
- 课程映射和家长报告示例。

本规范将在首批能力节点完成后进入公开 RFC。
