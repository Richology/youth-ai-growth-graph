# Richology Youth AI Growth Graph

An open framework, competency graph, and practical methodology for youth growth through AI-powered creation and commercialization.

The Chinese README is the primary project description. Node status and dataset counts are recorded in `data/manifest.json`.

The project contains three connected layers:

1. an open conceptual framework;
2. a machine-readable competency graph;
3. practical methods for course design, project learning, evidence collection, and parent communication.

It is not a validated psychometric assessment, a permanent label for young people, or an established industry standard.

See [README.md](README.md) for the current full introduction.
