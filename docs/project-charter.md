# 项目总纲

本文件是项目的简明立项说明。完整版本见 [《项目总纲与开源路线图 v0.1》](project-charter-full-v0.1.md)。后续重大定位调整应通过 RFC 留下公开记录。

## 项目定位

Richology 青少年 AI 时代成长图谱，是一套面向青少年 AI 创造与商业化教育的开放框架、能力图谱和实践方法论。

## 核心主张

不只展示学生做出了什么，还要说明作品背后哪些能力得到了发展，以及这些判断基于什么证据。

## 价值方向

本项目以财富、健康、关系三大人生课题作为长期价值方向，以 AI 技能化、商业化、职业化、社会化作为能力图谱的一级结构，以创造、创作、创新、创业描述进入真实世界的不同实践深度。

## 认识论边界

框架主要由实践经验和个人反思发展而来。过去课程经验说明它如何形成，但不被用作证明图谱正确性的验证数据。项目将通过公开评议、跨领域审阅、持续修订和未来研究逐渐提高可信度。
